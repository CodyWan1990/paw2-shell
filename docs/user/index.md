# paw2-shell documentation

paw2-shell is the desktop shell for the [paw2](https://github.com/CodyWan1990/paw2) Wayland compositor: bars, dock,
launcher, control center, notifications, lock screen, wallpapers and themes.

New here? Start with [Installation](getting-started/installation.md), then [Running paw2-shell](getting-started/running-the-shell.md). [How configuration works](configuration/index.md) explains where settings live and which file wins when Settings and your own config set the same option.
